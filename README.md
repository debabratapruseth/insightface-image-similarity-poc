# insightface-image-similarity-poc
Experimental InsightFace-based face embedding similarity POC using cosine similarity ranking, image quality checks, explainability, and reviewer-focused visual analysis in Google Colab.

This repository is an experimental face-embedding similarity POC using InsightFace.
It does not make identity decisions.
Outputs are similarity scores for human review only.
Do not upload private, sensitive, or unauthorized images to this repository.
